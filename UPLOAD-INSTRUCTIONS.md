# Publish the three design options
1. Open each option folder on GitHub.
2. Choose Add file > Upload files.
3. Upload the matching revised standalone HTML file and commit it.
4. Open the uploaded HTML file, select Edit, change its filename to index.html, and commit.
5. Repeat for all three option folders.
6. In Settings > Pages, select Deploy from a branch, main, and / (root), then Save.
7. Wait for deployment and copy the live URL shown by GitHub Pages.
8. Test the comparison page and each option on mobile before sending it to the client.

The root index.html is the comparison page. Do not replace it with an option. All repository files are public. No actual design HTML files have been uploaded by this setup commit.
